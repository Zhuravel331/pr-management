# PR-кампанія відкриття ресторану

Робочий документ команди: порядок робіт, чеклист здачі за лекцією «Планування PR-кампаній» і бриф концепції.

Концепція закладу: корейська кухня + суші-бар, Київ. Локація-кандидат — RestoPort / ЖК Рибальський.

---

## 1. Порядок роботи

Йти в цій послідовності, інакше креатив і календар роз’їдуться.

1. **Бриф закладу** — назва, кухня, локація з реальною орендою, чек, місія. Без цього наступні етапи не стартують.
2. **Аналітика** — конкуренти саме корейських / суші, SWOT, PEST, ЦА, контент-аналіз.
3. **Стратегія + креатив паралельно** — тип кампанії, публіки, канали, строки; окремо інсайт, меседж, УТП, тизер / ревіл, слоган.
4. **Календар, канали, прес-план** — Gantt на 3–6 місяців, план кожної події, прес-заходи.
5. **Матеріали** — лого, постер, 1 екран сайту, сценарій ролика, листівка, фото-референси, сувенір.
6. **KPI і ризики** — метрики зі слайда лекції та способи мінімізації зривів.
7. **Збірка презентації** — один файл, логіка лекції, єдиний стиль.

## 2. Чеклист здачі по слайдах

Лекція задає структуру роботи. Порожні слайди (5, 6, 9, 10, 13–15, 19, 21, 22) — приклади викладачки; копіювати їх не потрібно, але терміни з цих блоків у презентації мають бути.

### Слайд 1. Титул

- Назва закладу
- «PR-кампанія відкриття»
- Команда
- Місто

### Слайд 2. Тип кампанії

- Проактивна (відкриття), нерутинна
- 2 речення, чому це не «гасіння пожежі»

### Слайд 3. Стратегія

Обов’язковий блок. Закрити всі пункти:

- роль і місія закладу
- що хочемо змінити (знання / бажання / візит)
- ключові групи публіки
- ключові канали
- обмеження ресурсів (бюджет, час, локація)
- строки
- ризики (коротко; деталі — пізніше)
- як оцінимо ефект
- ключові події

### Слайд 4. Тип стратегії

Обрати 1–2 типи і пояснити:

- ривок
- швидкий фінал
- велика подія
- крейсерська

Для відкриття логічно: **велика подія + ривок**. Написати чому.

### Слайди 7–23. Креативна концепція

Серце здачі. У презентації — окремими кадрами або одним щільним блоком.

| Термін | Що здаємо | Критерій «готово» |
|---|---|---|
| Бенчмаркінг | 2–3 заклади «як роблять добре» | не список назв, а що саме беремо |
| Eye-catcher | що ловить око | 1 образ |
| Benefit | раціональний + емоційний | відповідь на «який мені з цього толк» |
| Insight | звичка / страх / потреба ЦА | можна переказати одним реченням |
| Main message | 1 меседж кампанії | не 5 меседжів одночасно |
| Take out | що людина має зрозуміти | різний для різних ЦА, якщо треба |
| УТП | чим заклад не як інші корейські / суші | особливість продукту або сервісу |
| RTB | доказ меседжу | факти, шеф, продукт, місце |
| Credibility / Demo / End benefit | як покажемо довіру і фінал історії | для ролика / постера |
| Key visual | 1 картинка всієї кампанії | її можна поставити на постер |
| Teaser → Reveal | загадка і розгадка | стилістика одна; у тизері немає продукту |
| Слоган | на роки | філософія бренду |
| Копілайн | девіз цієї кампанії | можна продуктову обіцянку |

### Слайд 24. Аналітика

- конкуренти (саме цей сегмент, не «всі ресторани Києва»)
- SWOT
- PEST
- ЦА (2–3 портрети)
- контент-аналіз (що пишуть / шукають / знімають)

Додаткова вимога з обговорення курсу: **реальна оренда = адреса + скрін оголошення**. Без цього стратегія не прив’язана до місця.

### Слайди 25–26. Календар

- загальний план усієї програми
- окремий план на кожну подію
- таблиця: етап → дати → звітність
- діаграма Ганта (хоча б спрощена)

### Слайд 27. Канали

Не загальне «будемо в Instagram», а навіщо кожен канал:

- SMM
- блогери
- e-mail
- сарафанний маркетинг
- особисті контакти
- контекстна реклама
- таргетинг

Можна не брати всі. Треба пояснити вибір.

### Слайд 28. KPI

Список зі слайда, перекладений на відкриття ресторану:

- публікації в динаміці
- частка позитив / негатив
- згадки закладу / організаторів / представників
- % матеріалів із ключовим меседжем
- типи ЗМІ
- брендинг (лого, фото)
- гості на подіях → конверсія у гостей ресторану

### Слайд 29. Ризики

Формат: вид ризику → як зменшуємо.

Обов’язково покрити:

- зрив строків
- локація / трафік
- тривоги
- зрив постачальників
- слабкий відгук ЗМІ
- негатив у соцмережах

### Слайд 30. Рекламні носії

Мінімум:

- логотип
- слоган
- принт постера
- 1 екран сайту
- сценарій ролика
- оголошення / продаючий текст
- листівка або сторіс
- фото-референси
- ідея сувеніра

### Слайд 31. PR-інструменти

Обрати 2–3, не всі:

- прес-конференція / брифінґ
- прес-тур або прес-сніданок
- інтерв’ю
- експертний коментар
- презентація
- як формуємо прес-пул

### Критерій здачі

Якщо викладачка гортає лекцію і презентацію команди паралельно — кожен блок лекції десь є. Неприпустимо: гарні сторіс без інсайту або аналіз без KPI.

## 3. Бриф

### Рішення, вже зафіксовані

- Формат: ресторан у Києві
- Кухня: корейська + суші-бар
- Обґрунтування кухні: корейська має високий пошуковий попит; суші логічно входить в азійську концепцію; на відміну від зв’язки «грузинська + рибна» це одна сцена, а не два різні заклади в одному залі
- Локація-кандидат: RestoPort / ЖК Рибальський. Кільком учасникам варіант зайшов. Це ще не фінал: потрібні ціна оренди, площа, технічні дані. Якщо їх немає — шукати іншу **реальну** адресу в оренді (вимога курсу: скрін оголошення + адреса)

### Відкриті питання

Закрити першими, до старту аналітики і креативу:

- назва
- точна адреса / чи команда залишається на Рибальському
- чек і ціновий сегмент
- місія одним реченням

### Предмет здачі

Не опис ресторану як такого, а **PR-кампанія відкриття** за структурою лекції:

стратегія → креативна концепція → аналітика → календар → канали → KPI / ризики → макети → прес-заходи.

Окремо: реальне приміщення в оренді.

### Наступний крок

Закрити назву і локацію. Без цього аналітика і креатив будуть про різне.
